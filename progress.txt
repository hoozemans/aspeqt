## Codebase Patterns
- AndroidManifest.xml is at `android/AndroidManifest.xml` — all manifest attributes are on single long lines
- No Android build toolchain (gradle/SDK) available locally; validate XML with `xmllint --noout`
- This is a Qt/C++ app with Android Java glue code in `android/src/net/greblus/`
- No Java compiler (javac) available locally; validate Java changes by manual review
- Git requires `DEVELOPER_DIR=/Library/Developer/CommandLineTools /Library/Developer/CommandLineTools/usr/bin/git` due to Xcode license issue
- SerialActivity request codes: 2=REQUEST_BLUETOOTH_CONNECT, 3=REQUEST_ENABLE_BT (request code 1 for WRITE_EXTERNAL_STORAGE was removed in US-009)
- Storage permissions (WRITE/READ_EXTERNAL_STORAGE) are limited to maxSdkVersion=28; SAF must be used on API 29+
- For async UI↔background thread coordination, use `Object.wait()/notifyAll()` pattern (see requestBluetoothEnable/waitForBluetoothEnabled)
- SAF request codes: 4=REQUEST_FILE_OPEN (file open via ACTION_OPEN_DOCUMENT); FileChooser Runnable still delegates to `fileChooser()` which branches on m_action
- SAF file open copies content URI to `getCacheDir()` so C++ polling code continues to get a regular file path via m_chosen
- SAF file save: C++ writes to cache file, then `flushPendingSave()` copies cache→content URI; flush is called at start of runFileChooser/runDirChooser and in onDestroy
- SAF request codes: 4=REQUEST_FILE_OPEN, 5=REQUEST_FILE_SAVE, 6=REQUEST_DIR_CHOOSE
- SAF tree URIs (ACTION_OPEN_DOCUMENT_TREE) use `DocumentsContract.getTreeDocumentId()` to extract `type:path` — "primary" maps to `Environment.getExternalStorageDirectory()`, other types map to `/storage/<type>/`
